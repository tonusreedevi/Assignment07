 Keen Keeper

 
Project Description:

Keen Keeper is a personal relationship tracking web application designed to help users manage and maintain their friendships and social connections.
It allows you to monitor how often you interact with your friends, track communication history, and gain insights into your social relationships through visual analytics.

Features:

 Analytics Dashboard : View overall friendship statistics in one place
 
 Pie Chart Overview : Visualize friendship status distribution (on-track, need attention, etc.)
 
 Responsive UI : Works smoothly across devices.

Technologies Used:

React.js

React Router DOM

Tailwind CSS

Recharts
